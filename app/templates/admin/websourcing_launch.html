Launch a Claude browser session

This hands the browsing-heavy part of sourcing to Claude on your computer: a Claude session with the Claude for Chrome extension (or a Cowork session linked to your computer) gets a real browser, reads this role's brief from the app, hunts public pages — portfolios, directories, team pages — and posts what it finds back here. Everything lands in the same review list, deduplicated and scored by the app; the same rules apply (public pages only, no logins, no LinkedIn scraping), and outreach still happens only in the app on your click.

Open in Claude ↗

"Open in Claude" pre-fills the prompt on claude.ai — press Enter there to start. For full automation (browser + API calls in one session), paste the prompt into a Cowork session in the Claude desktop app with your computer linked and Chrome connected. The prompt contains this app's API key — treat it like a password.

How results come back

The session calls GET /api/v1/websourcing/roles/{{ role.slug }}/brief for the JD and your latest targeting filters, then POST /api/v1/websourcing/candidates with what it finds. Each batch appears as a claude-browser run under Recent runs, and the candidates show up in the review list within seconds — scored, evidence-labelled, and never overriding anyone you already dismissed or moved.
